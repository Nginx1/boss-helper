# 简历与回复助手（0.7.0）

## 根据简历生成提示词

1. 在岗位页进入 **AI → 简历生成提示词**。也可在 BOSS 沟通页右上角的个人菜单打开 **简历与提示词**。
2. 导入 PDF、DOCX、TXT 或 Markdown，或直接粘贴简历文字。文件最多 8 MB，PDF 最多 20 页，正文最多 5 万字。
3. 核对提取文字的顺序和完整性，填写目标岗位、城市、薪资意向及其他明确限制。未填写的信息不会自动补造。
4. 点击 **生成三组提示词**，分别查看筛选、招呼和回复预览。模板根据简历原文生成，不在此步骤调用模型。可以直接修改预览文字。
5. 选择要应用的提示词，勾选已经核对事实，再点击 **应用选中的提示词**。投递正在运行时应先停止。

应用只更新所选功能的 `prompt`，保留模型、启用开关、筛选分数、招呼条数及延迟参数。需要实际启用筛选或招呼时，仍使用原来的 AI 配置开关。

**恢复上一次提示词** 对当前预设生效，只恢复上一次应用前的提示词内容，不把模型和开关退回旧设置。仅保留最近一次替换备份。

“保存简历到本机”是单独操作，不要求保存原文件。清除本机简历不会修改已经应用的提示词；若要清除其中的简历信息，也需要恢复或编辑这些提示词。

扫描图片式 PDF 暂不识别文字，会明确提示先 OCR；旧 `.doc` 请另存为 `.docx`。加密文件先去掉密码。表格、分栏和部分字体可能影响提取顺序，必须以预览为准。

## 回复草稿

1. 在 **回复助手** 选择模型。默认沿用招呼模型，未配置时沿用筛选模型；也可单独选择回复模型。
2. 保持页面打开。助手只处理消息连接建立后到达的新文字消息，不拉取旧聊天，不作为关掉浏览器后继续运行的服务。
3. 默认手动点击 **生成回复草稿**。需要收到消息就准备草稿时，勾选 **收到新消息时自动起草**。这不会自动发送。
4. 选择会话，核对接收人、近期问题、草稿和待确认事项，可以修改草稿。
5. 勾选 **我已核对接收人、最新消息和回复内容**，点击 **确认并发送这一条**。发送前沿用原消息延迟；投递仍在运行时需先停止投递，再继续回复辅助。

新问题会使旧草稿失效。停止辅助或已识别的手动输入会暂停辅助并取消未发布内容；也可对单个会话点击“人工接管”。重新启用需要点击“继续回复辅助”或针对该会话手动起草。

未知的薪资、离职、到岗、面试时间、接受条件和附件发送情况不应由模型承诺，都会留给本人核对。AI 草稿并不保证事实完全正确。

同一条 HR 消息不会重复提交。若已尝试发布但未收到可靠确认，会显示 **请核对发送结果**；先在 BOSS 原聊天核对，程序不会自动补发。

收到的最近对话只保存在页面内存中，刷新后消失。若没有收到新消息，请先核对页面消息连接状态。模型请求失败会暂停自动起草，检查配置后再继续。

## 数据去向

文件解析和模板生成均在本机完成。应用后的简历提示词，以及实际起草所需的近期对话，会发给本人配置的 AI 服务。原始文件不上传。详见 [数据与网络说明](../PRIVACY.md)。

PDF 提取使用固定随包的 [Mozilla PDF.js](https://github.com/mozilla/pdf.js)，接口依据 [PDF.js 文档](https://mozilla.github.io/pdf.js/api/draft/api.js.html)。许可证与文件校验信息随包保留。
